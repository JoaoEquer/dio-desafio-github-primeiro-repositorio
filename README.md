# Desafio de Projeto sobre Git/GitHub (DIO)

Repositório criado para o desafio de projeto de Git e GitHub da DIO (Digital Innovation One). Reúne também exercícios de HTML e CSS feitos durante o curso.

## Conteúdo

- `Introdução ao Git e ao GitHub/Anotações.txt` - anotações com comandos básicos de Git.
- `Introdução ao HTML/` - páginas `index.html` e `about.html`.
- `Trabalhando com Formulários em HTML/` - formulários (checkbox, radio).
- `exemplo-css/` - exemplos de seletores, combinadores, cores, fontes, margens, bordas, sombras e imagens de fundo.

## Tecnologias

HTML5 e CSS3.

## Como rodar localmente

Sem build: abra os arquivos `.html` no navegador (por exemplo `exemplo-css/index.html`).

Repositório de estudo (curso DIO).
